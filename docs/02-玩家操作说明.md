# 玩家操作说明 · 0.9.8

使用PICO手柄射线对准目标，轻扣扳机。应用在独立MR空间中运行。

## 第一次进入

1. 进入主菜单，选择“教学档案”。先完成“基本操作”“能量等分”“符文顺序”。
2. 点击“开始教学”，按当下唯一发光的目标行动；当前一步完成后再进行下一步。
3. 熟悉后回主菜单，通过旅程入口或星域选关继续游玩。

## 每关的解法逻辑

1. 先查看每个终点需要几格能量、什么符文顺序；同步关还要看到达拍数。
2. 点击机关中的插槽，再点击下方“装转向件”“装等分件”或“装棱镜”。
3. 用“出口 ‹ / ›”选择当前元件的出口。某些机关的出口选项同时决定比例、等待拍数或空间参数。
4. 实线表示当前选中的路径，虚线表示候选路径；交叉不等于连通。
5. 点击固定机关或终点读线索；库存不足可取回已安装元件。撤销支持最近20步。
6. 布置后点击“开始”。观察光点，必要时“暂停”“下一段”逐段查看，或“停止”回到编辑。
7. 所有终点同时满足该关规则才通关。失败时打开“目标”，比较要求与实收，用“定位错误”寻找首个问题。
8. 仍卡住可用每关最多3次的分层提示，或从“更多”进入重置、教学及其他选项。

## 进阶规则

- 等分件：把偶数能量均分到两个出口。
- 比例棱镜：按出口标注的比例分配能量，例如3＋1，不是任意分配。
- 符文检查点：经过后追加印记；终点锁检查完整顺序。
- 条件门：不符合所需印记串时会阻断。
- 换印器：替换最后一枚印记，保留前面的部分。
- 联动插槽：一处编辑会按规则同步影响另一处。
- 倒序镜：反转整串印记。
- 退印台：只去除最后一枚印记，空印记会被阻断。
- 同步关：路径时间和阀门等待共同决定到达时刻；静音时可看拍数，无需抢拍点击。
- 空间机关：在对应页面调整双桥臂、镜面或折返段，观察实际几何与读数，再返回主机关验证。

## 月印之门复测

主菜单 → 教学档案 → 符文顺序 → 开始教学。读终点锁印、读星印、选择A安装等分件、选择B安装等分件，按最后高亮点击“开始”。0.9.8会保留已经正确的默认出口，不再要求多转一次；请以当前高亮为准。

## 舒适度

可在设置调节星仪大小、画质、声音、舒适模式和装饰演出，必要时重新居中。支持按钮转视角观察，身体移动不是完成空间观察的必要条件。

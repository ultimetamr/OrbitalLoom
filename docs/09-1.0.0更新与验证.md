# 1.0.0 更新与验证

更新日期：2026-11-19。应用包名 `com.orbitalloom.puzzle`，versionCode 28。

## 交互

手柄射线对准晶体并按住扳机，拖入插槽后松开。手势操作使用捏合、移动、松手。已安装机关支持手腕旋转或圆周拖动，松手吸附档位；一笔操作对应一次撤销。取消、追踪点无效、暂停或切换关卡时恢复预览，不提交半次操作。

教学从主菜单进入“教学档案”，按当前高亮依次选择插槽、拖入水晶、旋转和开始。辅助按钮位于“更多 → 辅助操作”。本轮保留原 24 关，未新增关卡。

# 审核试玩说明 · 当前开发测试版

作品：Orbital Loom 星轨织机。包名：com.orbitalloom.puzzle。当前版本0.9.8/code25。

## 推荐检查顺序

1. 启动进入主菜单，确认按钮可读、射线与扳机可点击。
2. 教学档案 → 基本操作，逐步完成安装、调整与开始。
3. 教学档案 → 符文顺序，复测第3关“月印之门”；只按高亮完成，不额外旋转。
4. 星域选关检查四个星域与24关目录。
5. 教学档案 → 新机关教学，检查比例棱镜、倒序镜、退印台和同步节拍。
6. 空间观察教学分别体验第15、18、23关的双桥接合、镜面寻路、折返共鸣。
7. 一次错误布置后点击开始，查看目标比较和首错定位；尝试停止、撤销、重置。
8. 返回菜单再进入关卡；重启应用确认通关进度与设置保留。
